# Eksperimen Perhitungan SAW-TOPSIS

## Deskripsi
Repository ini berisi eksperimen Sistem Pendukung Keputusan (SPK)
menggunakan metode Simple Additive Weighting (SAW) dan
Technique for Order Preference by Similarity to Ideal Solution (TOPSIS).

## Isi Repository
Folder EKSPERIMEN SPK berisi:

1. Dataset SPK Fasilitas Kesehatan
2. Program eksperimen dalam Python (Jupyter Notebook)
3. Grafik hasil pemeringkatan TOPSIS
4. Hasil eksperimen replikasi dalam Excel
5. Hasil gabungan metode SAW-TOPSIS dalam Excel

## Tools
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Google Colab / Visual Studio Code

## Metode
- SAW (Simple Additive Weighting)
- TOPSIS (Technique for Order Preference by Similarity to Ideal Solution)
